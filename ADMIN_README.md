# HFT Trader — веб-админка

Одна статическая страница, сборка не нужна. Бот только отдаёт HTTP API; админка — отдельно.

1. Откройте `index.html` в браузере (или раздайте папку: `python3 -m http.server 8000`, nginx и т.п.).
2. В шапке укажите адрес API бота (по умолчанию `http://localhost:8080`) и `ADMIN_TOKEN`.
   Оба значения сохраняются в браузере.

Порт API бота наружу не открывайте — SSH-туннель: `ssh -L 8080:localhost:8080 сервер`.

## Вкладки

| Вкладка | Что там |
|---|---|
| Обзор | Поднять/остановить соединения, торговля вкл/выкл, PANIC, автостарт. По каждой бирже: рынок (spot/perp и плечо), режим LIVE/PAPER, testnet, данные, состояние сокета ордеров (готов, ошибки разбора, уходы в REST), PnL за день, отказы, kill switch |
| Биржи | Каталог с доступными рынками и комиссиями (спот и перп). Выбор биржи сразу с рынком и плечом, добавление/удаление символов |
| Параметры | Параметры выбранной биржи по группам (рынок, подключение, риск и комиссии, стратегии, фиды, Uniswap), поиск, подсветка изменённых; ⟳ — после перезапуска соединений |
| Стратегии | Стратегии каждой биржи (возврат к среднему, статарбитраж, треугольный) с переключателями и статистикой; межбиржевые — funding-арбитраж, ценовой арбитраж перпов, cash-and-carry: включение, открытые позиции, возможности с комиссиями и окупаемостью |
| Позиции | Позиции по фьючерсам (сторона, вход, mark, нереализованный результат), закрыть одну или все (reduceOnly), ставки funding |
| Рынок | Стаканы, z-score, балансы выбранной биржи |
| Ордера | Ручной ордер; на фьючерсах подсказка (SELL — шорт, «весь баланс» = маржа × плечо), закрыть позицию символа, отменить ордера |
| Подбор | Подбор тикеров под стратегии, «в выбор» одной кнопкой |
| Настройки | Настройки процесса по группам: межбиржевые стратегии, подбор тикеров, процесс |
| Окружение | Файл `.env` бота: ключи бирж, режим (`<БИРЖА>_TESTNET`, `<БИРЖА>_LIVE`), токен и порт; секреты не показываются |

Опасные действия (включение торговли и стратегий, PANIC, закрытие позиций, ручной ордер) спрашивают подтверждение.
Вкладки с формами не перерисовываются автообновлением, пока вы их заполняете.
